# Product card system — mock-ups

```
open docs/design/product-card-system/index.html
```

Static overview of all three variations first — every card state in a grid, plus the matching
product-page states — then click a variation for the interactive version: hover the cards, tab
through them, switch Digital ↔ Printed, toggle 1440 / 390 and EN / SK.

The rules live in `docs/design/PRODUCT-CARD-SYSTEM.md`. This folder is the picture of them.

`index.html` overview + switcher · `frame.html` one interactive page (`?v=1|2|3&lang=en|sk`) ·
`cards.css` the three variations · `cards.js` states, copy and the single card builder.

Nothing here is in the theme.
